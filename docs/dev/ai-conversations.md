# AI 会话与工具链规范

适用：AI 对话、全局浮层、桌面窗口、供应商、附件、知识/记忆和 MCP。依据 2026-11-15 已确认的 AI 体系改造方案。

## 历史、模型上下文与运行任务

- `AIMessage` 保存完整原始历史；`AIConversation.Messages` 保留旧 JSON，仅作兼容导入，不覆盖、不删除。模型预算裁剪、工具结果降噪和摘要都只能影响模型输入视图。
- 前端启动只提交新正文、附件 ID、设置、版本和请求幂等键。不要提交裁剪后的历史作为保存真源；元数据更新不得重写消息。
- `AIRun` 保存运行检查点、终态与上下文用量。浏览器连接和后端生成分别管理；切换/关闭页面只 detach，明确停止才调用 stop。
- 运行按会话互斥，重复请求使用同一幂等键；写工具不因网络重连、页面刷新或服务重启而自动重试。重启恢复为 interrupted，展示最后保存的进度。
- SSE 使用服务端 `runId + eventId`，快照和最后游标在同一把锁内取得。重复事件忽略，序号缺口立即重新获取快照；不能用收到的帧数计算 offset。完成态返回快照，不追加重复 assistant。
- 所有订阅退出必须清理；慢订阅关闭并重同步，不静默丢增量。前端所有异步回调须绑定会话/订阅代次与账号代次；多个视图共用 Pinia 中同一会话的一条有效流。

## 上下文与模型协议

- 窗口、输出预留、系统/技能、检索数据、摘要、消息、附件与工具 Schema 统一纳入预算。无法准确分词时明确标估算；供应商返回的 usage 单独展示，不能假装为精确上下文占比。
- 默认窗口 32768、输出 4096、80% 可用输入预算触发摘要、保留最近 4 个完整轮次；管理员模型能力和用户/会话设置可覆盖。不能按模型名称正则猜窗口。
- 摘要是独立无工具请求，按窗口有界分块。原文不变，保留目标、约束、决策、实际结果和待办；失败保留历史并明确提示。未决审批不能靠压缩消失。
- 工具调用与结果成对保留。大结果保存为可鉴权下载的脱敏附件，消息保存预览和结果 ID；不能只存一段截断文本却标“完整结果”。
- OpenAI-compatible、Anthropic 和 Responses 使用各自协议。Responses 在同次工具循环中原样保留返回的 output items/加密 reasoning，不自行伪造或丢弃签名。
- 模型能力以配置为准：`vision`、`tools`、`contextLimit`、`maxOutputTokens`、`temperature`、`maxTokensField`。图片必须显式声明视觉能力；切换模型时同时校验已有图片历史。采样留空应省略字段、沿用供应商默认值，显式 0 应保留。
- `maxTokensField` 可指定 `max_tokens` / `max_completion_tokens`；未指定时官方 OpenAI 使用后者，其他 OpenAI-compatible 端点使用前者。禁止同时发送两者。

## 权限与数据来源

- 会话、附件、记忆和知识资源须检查属主。旧版 owner=0 内容只对超级管理员可见；共享内容需要管理员显式发布，不能把旧数据自动分配给当前用户。
- 审批/提问绑定 user/conversation/run，并原子消费一次。多会话不能复用全局单槽审批状态；回放不能自动拒绝其他会话的审批。
- 所有工具仍经过 RBAC、节点范围、危险操作锁与审计；聊天权限档位不授予额外后端权限。外部 MCP 风险未知时，即使 full 也要确认。
- 记忆和知识检索在数据库中对候选评分、限量返回，再合并全局前 3 条；禁止把所有正文/分块先读入 Go 再截前三，单条检索视图须有界。
- 场景摘要不直接绕过业务服务读取整台主机或全表；只传页面/焦点提示，详情经授权工具按需查询。检索、文件和场景内容作为数据消息，不升级为系统指令。
- 审计关联 caller/conversation/run/tool call，参数、结果、错误统一脱敏，覆盖嵌套对象、数组、纯文本、Bearer、连接 URL 和私钥。
- 工作空间是宿主目录，不是沙箱。文件复用文件权限，命令复用终端权限、节点范围、危险锁与审计；没有实际隔离就不能展示隔离承诺。

## 附件、渲染和出站

- 单文件最多 20MB；图片最多 8MB、40MP、单边 16384。校验内容类型、尺寸、UTF-8、文档解压与提取上限；随机存储键，禁止使用用户文件名作存储路径。
- 支持 PNG/JPEG/WebP、UTF-8 文本/源码、DOCX 与有文本层 PDF。PDF 当前使用 `pdftotext`（部署需提供 poppler-utils）；缺依赖、扫描/加密/损坏 PDF 必须报出可操作错误，不假装上传后模型已读到内容。不包含 OCR。
- 小文档全文、大文档检索片段进入预算，提供来源与 `read_attachment` 分页深读。原始文件、提取文本与对话关联分别管理，分支通过引用保留文件。
- 未关联或引用已删除的附件至少保留 24 小时；启动、上传和删除会话时回收符合条件的文件。有关联的附件不能从草稿移除接口单独删除。
- 所有 Markdown HTML sink 必须经过 DOMPurify；远程图片不自动加载。代码高亮输出同样清理；静态 Markdown/高亮缓存有界，流更新合并，避免 deep watch 整个历史。
- DOMPurify 为直接依赖，使用 Apache-2.0 授权；marked 只负责解析，不能替代 HTML 清理。代码高亮复用现有 Monaco，不新增另一套编辑器/组件体系。
- 模型与 HTTP MCP 端点逐跳校验同源、IP 与重定向。私网地址由管理员对该端点显式开启；校验要放在 HTTP transport 中，不能只检查 Do 包装而让 SDK 绕过。

## 验证入口

- Go：`GOTOOLCHAIN=local go test -race ./internal/service ./internal/api ./internal/rbac ./internal/middleware -run 'TestAI|TestCheckTool|TestNode'`，并执行 `go test ./internal/service/ -run TestAITools`。
- 前端：`pnpm exec node --experimental-vm-modules --test tests/ai-chat.test.mjs`，应用 `vue-tsc -b`、相关 ESLint/Stylelint 和 `vite build`。
- 浏览器使用本地模拟端点验收长历史、生成中切换、重复视图、窄屏/主题、设置与附件；模拟验证不能宣称为真实供应商兼容性实测。
